# Derivative website

A standalone presentation site for the Derivative browser. Uses HTML, CSS, and JavaScript, with no framework or dependency installation required.

```sh
npm run dev
```

Open http://127.0.0.1:4173. Run `npm run build` to create a deployable static `dist/` folder.

The interactive browser is an illustrative preview: switch Spaces, select tabs and favorites, search preview pages, or explore the Spaces, Sidebar, Split view, and Search feature tabs. The feature tabs support arrow keys, Home, and End. The FAQ uses native disclosure controls. The build button links to the native browser's real source instructions; no packaged download is currently advertised.

Uses the local Helvetica Neue / Helvetica / Arial font stack. No external font requests. Visual assets are local SVG and CSS.
