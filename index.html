A few things to know.

Can I download Derivative?

Derivative is currently built from source. You’ll need an Apple Silicon Mac running macOS 14 or later, Python 3.12+, and Apple’s command-line tools. The repository includes the build instructions.

What works today?

Spaces with separate website storage, favorites, pinned tabs and folders, split view, floating search, downloads, and sidebar customization. The README covers the current limits.

Does it support extensions and sync?

Extensions, built-in sync, and a password manager are not implemented yet. Derivative is under active development.

Is this connected to Arc or The Browser Company?

No. Derivative is an open source project by A Browser Guy. Arc is an inspiration for parts of the browsing experience.
