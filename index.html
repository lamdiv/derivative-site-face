What it actually is

Tabs
Pin pages, nest them in folders, drag them between Spaces. The sidebar is the tab strip.
Keys
⌘T opens search. ⌘S toggles the sidebar. The rest is meant to stay out of the way of the page.
Native
SwiftUI and AppKit draw the interface. CEF runs Chromium for the websites themselves.
Limits
No extensions, no sync, no password manager. It is early, and the README lists what is missing.

Independent of Arc.
Inspired by the same habits.

Favorite places, a sidebar a shortcut away, Spaces that don’t leak cookies into each other. Derivative is a separate project by A Browser Guy. The source is public because the browser should outlast any one company.

Before you clone it

Can I download a build?

Not yet. You compile it on an Apple Silicon Mac running macOS 14 or later, with Python 3.12+ and Apple’s command-line tools. The repository has the steps.

What works today?

Spaces with separate website storage, favorites, pinned tabs and folders, split view, floating search, downloads, and sidebar customization. The README covers the current limits.

Extensions, sync, passwords?

None of those are implemented. File an issue if you want to work on one of them.

Is this Arc, or The Browser Company?

No. Derivative is an independent open source project. Arc is an influence on the browsing model, not an affiliation.

Build it on your Mac

Clone the repo, follow the local run instructions, and compile. Developer tools required. No packaged download.
